# PL - Portfolio 

Portfolio jest projektem strony internetowej będącej  skrótowym przedstawieniem mojego dotychczasowego doświadczenia oraz działalności.
Celem tej strony jest przedstawienie mojego CV w postaci wygodnej do przeglądania na dowolnym urządzeniu.

## Technologie

Strona wykorzystuje Vue.js 3 jako SinglePage Application, ASP.NET API jako warstwa backendu oraz komunikacja z repo GitHuba.

## Status

W trakcie rozwoju.
Aktualnie wersja 1.1

# EN - Portfolio

The portfolio is a website project that provides a concise overview of my experience and activities to date.
The purpose of this website is to present my CV in a format that is easy to view on any device.

## Technologies

The website uses Vue.js 3 as a Single Page Application, ASP.NET API as a backend layer, and communication with a GitHub repo.

## Status

In development.
